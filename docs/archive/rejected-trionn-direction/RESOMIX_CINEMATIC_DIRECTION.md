## What Resomix takes (translated, never copied)

1. **One anchor per page.** Trionn's evolving letterform becomes a Resomix-native sonic object per page: sonic core (Product Overview), reference-node fan (Sonic Discovery), spectral layer stack (Track Intelligence), catalogue constellation (Catalogue Intelligence), signal-to-endpoint flow (Developers). Phase 1 builds these as SVG/CSS/canvas-2D geometry; 3D is a later, separately-approved upgrade path.
2. **Typography as interface.** Huge light Helvetica editorial statements; Fira Code micro-labels as far-apart information islands; Benzin only as the rare accent. Scroll-scrubbed word emphasis for one long claim per page at most.
3. **Signal trajectories.** Fine lines with nodes connecting real things — core to surfaces, reference to matches. They extend the existing dotted-line language; the `SideLines` frame stays the outer boundary.
4. **Resolution motion.** Blur-to-focus (hero, once), draw-ins, illumination sweeps. Nothing loops except the layout-owned StaticNoise. Everything has static, reduced-motion, and mobile forms.
5. **Dark-first with deliberate inversion.** The existing `.light` token set becomes a dramatic instrument: at most one light punctuation band per page, if approved.
6. **Instrument-panel affordances.** Written labels in Fira Code (`status: beta`, `SCORED BY PYXIS-1`) — true statements only.
7. **Calm where it matters.** Trust is intentionally the least cinematic page; enterprise pages run restrained.

## What Resomix refuses

Content gated behind a preloader; scroll hijacking; horizontal-takeover galleries (P1); sound-reactive UI; a second animated background; new animation/3D dependencies in Phase 1; any Trionn asset, model, text, or chrome; literal space illustration (planets/astronauts/stars) — the "space" is negative space, scale, and signal.
