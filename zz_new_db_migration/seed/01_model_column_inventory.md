# Model and Column Inventory (Final Precision)

This document provides a comprehensive and exhaustive inventory of all SQLAlchemy models in the Resomix FastAPI backend. This serves as the source of truth for Step 1 of the database seeding process.

## 1. Core Music Metadata

### [Track](file:///Users/muhammadusmannaeem/Data/projects/Upwork/George/basic_fastapi_server_resomix/app/models/track.py) (`tracks`)
- `id`: INT UNSIGNED (PK, AUTO_INCREMENT)

- `party_id`: VARCHAR(100) (FK -> parties.party_id, NULLABLE, INDEX)

- `display_artist`: VARCHAR(512) (NULLABLE)
- `duration_ms`: INT UNSIGNED (NULLABLE)

- `key_signature`: VARCHAR(10) (NULLABLE)
- `audio_language`: VARCHAR(2) (DEFAULT: 'xx')
- `language_of_lyrics`: VARCHAR(10) (NULLABLE)
- `genre`: VARCHAR(255) (NULLABLE)
- `sub_genre`: VARCHAR(255) (NULLABLE)
- `price_cents`: INT UNSIGNED (DEFAULT: 99)
- `mix_name`: VARCHAR(150) (DEFAULT: 'Original Mix')
- `track_type`: VARCHAR(50) (DEFAULT: 'electrobuzz')
- `p_line_year`: YEAR (NULLABLE)
- `p_line_text`: VARCHAR(512) (NULLABLE)
- `deal_terms`: JSON (NULLABLE)
- `parental_warning`: ENUM('NoAdviceAvailable', 'NotExplicit', 'Explicit', 'ExplicitContentEdited') (DEFAULT: 'NotExplicit')
- `is_explicit`: BOOLEAN (DEFAULT: FALSE)
- `is_instrumental`: BOOLEAN (DEFAULT: FALSE)
- `is_active`: BOOLEAN (DEFAULT: TRUE, INDEX)
- `ingestion_source`: ENUM('ddex', 'cc_by', 'user_upload', 'csv') (DEFAULT: 'user_upload', INDEX)
- `created_at`: DATETIME (SERVER_DEFAULT: CURRENT_TIMESTAMP)
- `updated_at`: DATETIME (SERVER_DEFAULT: CURRENT_TIMESTAMP, ONUPDATE: CURRENT_TIMESTAMP)
